Add a public RSS or Atom feed to include its stories in your news selection.

## Add a feed

1. Open **Sources → My sources → Add a source**.
2. Choose **Feed URL**.
3. Paste the site's feed address into **Feed URL (required)**. Look for an RSS or Subscribe link on the site.
4. Enter a **Name** and choose at least one interest.
5. Use **Test now** to check the feed, then select **Add** to save it.

The source starts with your subscription enabled. Adding it does not regenerate an existing digest.

## Check the result

**Test now** reads recent posts from the last 30 days and shows up to five headlines. It does not save the source or add stories to a digest. Source tests allow six requests per minute.

The feed must be reachable at a public HTTP or HTTPS address. Private network addresses and feeds requiring a login are not supported by this form.

You can save up to 30 custom sources. Choose **Edit** to change a feed later. To switch between a feed and a newsletter inbox, create a new source.
