Create an API key on a supported provider's site, then add it to Pulse. Free access depends on the provider, your account and the model you choose.

## Open a provider's key page

These are the same links offered by Pulse's AI key form:

| Provider   | Key page                                                         |
| ---------- | ---------------------------------------------------------------- |
| Gemini     | [Google AI Studio](https://aistudio.google.com/apikey)           |
| Anthropic  | [Anthropic Console](https://console.anthropic.com/settings/keys) |
| OpenAI     | [OpenAI Platform](https://platform.openai.com/api-keys)          |
| Groq       | [Groq Console](https://console.groq.com/keys)                    |
| OpenRouter | [OpenRouter](https://openrouter.ai/keys)                         |
| Z.AI       | [Z.AI key management](https://z.ai/manage-apikey/apikey-list)    |

Some providers offer free tiers. Check the provider's own pricing and terms to find out what your account can use. Pulse's provider list is not a promise of free access.

## Add it to Pulse

Copy the key into **Settings → AI keys → Add a key**. Choose a model your account can access, then use **Test the key** before saving.

Keep the key private. If you share it accidentally, revoke it with the provider and replace it in Pulse. See [Add and order your keys](/docs/ai-keys/add-and-order-your-keys).
