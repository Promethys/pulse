Use [GitHub issues](https://github.com/Promethys/pulse/issues) to report a bug, ask a question or suggest an improvement.

## Write a useful report

Include the page you were using, the steps that led to the problem, what you expected and what happened instead. For a display or browser problem, include your browser and device type.

For a digest problem, include the digest kind, date, selected timezone and any error message you can safely share. Say whether the post appears in the app and whether a delivery test succeeds.

## Keep private details out

GitHub issues are public. Do not include passwords, API keys, webhook URLs, recovery codes, personal email addresses or private newsletter content. Remove secrets from any error text before posting.

For a privacy or account request, use the email address on the [Privacy](/privacy) page instead of a public issue.

For catalog additions, use [Suggest a source or interest](/docs/interests-and-sources/suggest-a-source-or-interest) inside Pulse so the suggestion reaches the review queue.
